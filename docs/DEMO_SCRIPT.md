# Demo Script — AI Study Copilot (2-minute walkthrough)

Use this when showing the app to an interviewer, a judge, or when recording a
demo video. Everything below uses the **seeded demo account**, which already
contains a processed PDF and a graded quiz, so you can start immediately.

## Script

### 1 · Dashboard (10 s)
- Log in → you land on `/dashboard`.
- **Say:** "This is the study dashboard. It already knows about a neural-network
  lecture PDF the demo account uploaded — you can see the knowledge base is
  ready, plus quiz scores and a personalized review queue."
- Point at: Recent documents (status **Ready**), Quiz scores (67%), Recommended
  topics (Dying ReLU).

### 2 · Documents (10 s)
- Open **Documents**.
- **Say:** "The PDF is indexed — 9 chunks are in the vector database. Upload is
  drag & drop; every file shows a processing status, and failed files can be
  retried. Files are stored privately per user (RLS)."
- Optional wow moment: drag in `samples/linear-algebra-quick-reference.txt`
  and watch `Queued → Processing → Ready` in a few seconds.

### 3 · AI Tutor (30 s) — the highlight
- Open **Tutor**, ask: `What is backpropagation?`
- **Say:** "The answer is generated by DeepSeek, but **only from this student's
  own PDF** — retrieval is semantic search over their chunks in pgvector.
  Every claim cites the exact source passage."
- Click the `[1]`/`[2]` source chips → show filename + similarity + excerpt.
- Ask an off-topic question (`What is the capital of France?`) → **Say:**
  "It honestly says the material doesn't cover it, instead of hallucinating."

### 4 · Quiz (30 s)
- Open **Quiz**, pick the neural-networks PDF, generate (3–10 questions).
- Answer 1–2 questions (radio / True-False / short answer), submit.
- **Say:** "MCQ and True/False are graded deterministically; short answers are
  AI-graded. You immediately get a score, per-question explanations, and weak
  topics — which feed the insights."

### 5 · Insights (15 s)
- Open **Insights**.
- **Say:** "Across all quizzes it aggregates per-topic accuracy: strong topics
  vs. needs-review, with a score history. This is the learning loop: read,
  practice, diagnose, improve — not a chat wrapper."

## Notes & common questions

- **Why DeepSeek?** Chat provider is pluggable (any OpenAI-compatible API).
  Embeddings run **locally** via transformers.js — no second API account.
- **Security:** RLS end-to-end, secrets stay server-side, prompt-injection guard
  (document text is data, not instructions).
- **Stack:** Next.js 16 + Supabase (Postgres, pgvector HNSW, Storage, Auth) +
  DeepSeek + local embeddings; 76 unit tests.
- A hydration warning may appear in dev console if a browser translation
  extension (e.g. Immersive Translate) is installed — harmless, cosmetic.
